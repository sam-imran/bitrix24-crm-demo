
# Bitrix24 CRM Extensions (Demo)

Примеры продвинутых решений на ядре D7 для корпоративных проектов на Bitrix24 (коробочная версия).

## 🧩 Что внутри

- **Компонент `lead.report`**  
  Генерация Excel-отчета по лидам и сделкам с использованием фильтра, кастомных стадий и вычислений.

- **Компонент `lead.history`**  
  Отображение истории активности по лидам с разбивкой по событиям.

- **Обработчики событий**  
  - Автоматическое назначение ответственного в лиде по первой активности (дело, задача, звонок)
  - Автопривязка контакта при создании лида
  - Кастомные вкладки в карточке сделки
  - Принудительная смена пароля при создании пользователя

- **Миграции (`sprint.migration`)**  
  Пример миграции для отключения системных шаблонов приглашения и правки писем восстановления пароля.

## 🛠 Стек

- PHP 8.x
- Bitrix24 (коробочная версия)
- Ядро D7 (`Bitrix\Main`, `Bitrix\Crm`, `Bitrix\Tasks`, `Bitrix\Voximplant`)
- Composer (для `SimpleXLSXGen`)
- Sprint Migration

## ✅ Подход

- Использование современных возможностей ядра D7: ORM, runtime, ajax-контроллеры
- Чистый и понятный код
- Соблюдение стандартов PSR-12, PHPDoc
- Логика разбита на классы, каждый из которых отвечает за свою зону ответственности
